# Instructions du projet Domaine de Boudnib

## Vérification et livraison des modifications

Applique ces règles automatiquement à chaque demande de modification du code du projet.

1. Identifie la branche Git active et utilise la branche demandée pour la livraison.
2. Modifie et enregistre les fichiers concernés.
3. Exécute les vérifications adaptées et confirme que les modifications fonctionnent correctement.
4. Crée un commit avec un message clair. Limite le commit aux changements de la demande.
5. Pousse le commit sur la branche GitHub concernée.
6. Vérifie sur GitHub que le push a réussi et que le commit ainsi que les fichiers modifiés sont accessibles.
7. Dans le compte rendu, indique la branche utilisée, le statut de l’envoi, le chemin exact et le lien GitHub direct de chaque fichier modifié, ainsi que le lien du dernier commit de la demande.

Considère la modification comme livrée seulement après avoir confirmé le push sur GitHub. Si le push est bloqué, explique la cause et indique à l’utilisateur l’action nécessaire pour débloquer l’envoi.
